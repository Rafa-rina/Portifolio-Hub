# 🚀 Hub de Portfólio - Rafael Fernandes Durães

Bem-vindo ao meu **Hub de Portfólio**! Este é um espaço interativo desenvolvido para reunir e apresentar os projetos, atividades acadêmicas e evolução prática desenvolvidos ao longo do **4º semestre** na disciplina de **Desenvolvimento Web**.

## 🛠️ Tecnologias Utilizadas

No desenvolvimento das atividades presentes neste portfólio, foram aplicadas as seguintes tecnologias:

* **HTML5:** Estruturação semântica de páginas e integração de mídias (áudio/vídeo).
* **CSS3 (Vanilla):** Estilização personalizada, animações fluidas, efeitos de hover, gradientes modernos e layouts responsivos (Flexbox/Grid).
* **Bootstrap:** Desenvolvimento ágil de layouts responsivos, grids e componentes utilitários (como carrosséis de imagens).
* **JavaScript:** Validação dinâmica de dados, controle de fluxo de login e interações em tempo real.

## 📂 Atividades & Projetos Desenvolvidos

O portfólio é composto pelas seguintes seções e atividades práticas:

### 1. 📚 Apresentação (`apresentacao.html`)
Primeira atividade desenvolvida na disciplina. Contém uma breve apresentação pessoal, objetivos acadêmicos e uma introdução básica aos conceitos iniciais de estruturação web.

### 2. 📝 Listas, Tabelas e Formulários (`listas.html`)
Página focada no aprendizado de elementos essenciais do HTML. Contém listas ordenadas e não ordenadas, tabelas estruturadas e formulários completos com diferentes tipos de inputs.

### 3. 🎬 Menu, Classes, Imagens e Vídeos (`menu.html`)
Implementação de um menu de navegação personalizado e estilizado. Explora o uso de classes CSS para manipulação de layout, além da incorporação e otimização de mídias como imagens de alta qualidade e vídeos.
* *Acompanha relatório em PDF na pasta de documentos.*

### 4. 🎧 Cards e Áudio (`cards.html`)
Criação de um layout moderno com cards estilizados e a integração de um player de áudio personalizado, trabalhando com estilizações de fundo e elementos interativos.
* *Acompanha relatório em PDF na pasta de documentos.*

### 5. 📸 Ensaio Fotográfico (`fotografia.html`)
Galeria de fotos sofisticada que utiliza a biblioteca **Bootstrap**. Conta com um carrossel dinâmico de imagens e a integração de um reprodutor de trilha sonora em segundo plano.
* *Acompanha relatório em PDF na pasta de documentos.*

### 6. 🔐 Sistema de Saúde - Login (`login.html`)
Interface para simular uma tela de login hospitalar. Possui validações completas usando **JavaScript** para verificar matrícula, senha e cargo selecionado, garantindo maior interatividade e segurança lógica na entrada de dados.
* *Acompanha relatório em PDF na pasta de documentos.*

### 7. 🎮 GameTECH (`gametech.html`)
Uma landing page voltada para o comércio eletrônico (e-commerce) de produtos gamer. Possui catálogo de jogos, seções de acessórios de informática e um design escuro com luzes neon inspirado no público de jogos.
* *Acompanha relatório em PDF na pasta de documentos.*

### 8. 🍧 Dindins Gourmet Dona Socorro (`GELADINHO - DONA SOCORRO/DONA SOCORRO/index_dindins_dona_socorro.html`)
Landing page premium criada para apresentar um negócio de sobremesas gourmet tradicionais. Conta com vídeos em loop no background, galeria com efeito lightbox e uma seção dedicada ao storytelling (história afetiva da marca).
* *Acompanha relatório em PDF na pasta de documentos.*

### 9. 🏆 Panini - Copa do Mundo 2026 (`copa.html`)
Projeto temático baseado no famoso álbum de figurinhas da Copa do Mundo. Inclui um visualizador interativo para figurinhas raras (como a do Pelé), tabelas dinâmicas de classificação dos grupos, cronograma dos jogos e uma árvore de chaveamento para a fase eliminatória.
* *Acompanha relatório em PDF na pasta de documentos.*

## 🚀 Como Executar o Projeto Localmente

Como o portfólio foi feito puramente em tecnologias front-end estáticas (HTML, CSS, JS), rodá-lo é extremamente simples:

1. **Clonar o Repositório:**
   ```bash
   git clone https://github.com/Rafa-rina/Portifolio-Hub.git
   ```
2. **Navegar até a pasta do projeto:**
   ```bash
   cd Portifolio-Hub
   ```
3. **Abrir a página principal:**
   * Basta abrir o arquivo `index.html` em qualquer navegador web de sua preferência (Chrome, Edge, Firefox, Brave, Safari).
   * Se estiver usando o **VS Code**, é recomendável utilizar a extensão **Live Server** para rodar o projeto localmente com recarregamento automático (auto-reload).
